# Как сформирован скилл

Проанализированы история чата «Развернуть шаблон видеомонтажа» проекта «Монтаж ТОП» от развёртывания 23 октября до финальной сборки 5 ноября 2026, а также правила, профиль, код и проверенный MP4. Персональные исходники, настройки клона и полный журнал переписки в комплект не входят.

## Приоритет решений

Финальный эталон и последние явные правки → действующий STYLE_SPEC/profile → технические базовые правила → старые исторические варианты. Новое прямое указание студента может изменить его собственный стиль. Отложенные планы не считать реализованными функциями эталона.

| Этап | Что было задано | Что действует в скилле |
|---|---|---|
| Начальная основа | Remotion, локальная транскрипция, удаления пауз, вертикальный кадр, отдельные исходник/голос/субтитры, обратимые версии | Сохранено; это техническая основа |
| Исходные настройки | −35 dBFS, паузы от 0.2 с, сохраняемые куски от 0.3 с, первоначальный общий padding 0.2 с | Порог адаптируется; вместо одного общего padding — защита границы слова 0.03 с, 0.04 с до и 0.07 с после. Это сохраняет согласные без лишних пауз |
| Первые референсы 23 октября | Хук → пример → механика → вывод/CTA, лицо/50:50/графика; реальные результаты | Сохранены смысловая режиссура и связь графики с речью; чужие цифры не переносятся |
| Повторная переработка 24 октября | Автор отклонил поверхностный разбор; нужны конкретные предметы, крупные примеры, действия, а не одинаковые карточки | План объект→действие→результат обязателен, сцены проверяются во времени |
| Главный ранний референс | Montserrat, оранжевые акценты, CTA-кодовое слово | Исторический вариант; последняя типографика и палитра заменили его |
| Условная демонстрация | Для отдельного ролика разрешена авторская графика Claude/Canva вместо скринкаста | Можно объяснять процесс условной сценой; нельзя выдавать её за настоящую запись продукта или результат |
| Правки 1 ноября | Сначала менять только графику, сохранить хук/шрифт; светлая проба отклонена, оранжевый возвращён | Это ограничение той версии; 3 ноября автор явно разрешил полный рестайлинг |
| Последние 3 референса, 3 ноября | Полностью ориентироваться на новые хук, заголовки, субтитры, графику, элементы, анимацию | Onest/Unbounded, кремово-сиреневый фон, лайм, чёрные заголовки — текущий стандарт |
| Русская аудитория | Убрать ненужные англоязычные доказательные сайты, сделать простые контекстные иллюстрации | Русские подписи; внешнее исследование только по задаче, без декоративных статей |
| Нечитаемые субтитры | Белые буквы сливались с верхней светлой вставкой | Split Y=1008 вместо 960; тёмный контур 1.5 px и ближняя тень |
| Музыкальный проход | Добавить органичный фон, голос заметно громче; анализ треков конкурентов отложен | Отдельный разрешённый трек, ducking/fades; аудиоанализ опционален |
| Финал | Удалить непонятный вопрос и «напиши 1 2 3 4» | Финальная исходная фраза без придуманного CTA; у студента CTA только из его речи/задачи |
| Самая последняя правка | Пример программного цикла/1 2 3 не соответствовал мысли | Понятный вопрос о контенте, связный ответ и цепочка запрос→черновик→правка; для нового видео пример строится по его теме |
| Финальная сборка 5 ноября | Новый исходник «Первый заказ с ИИ», восемь сцен, хук должен проходить за силуэтом, музыка и прозрачные субтитры | Это новый основной эталон: объектная непрерывность, перспектива, быстрые входы без пустых первых кадров, источник→действие→результат, source-specific matte для depth hook и проверенный ducking |

## Что нельзя универсализировать

Собственный голос автора HeyGen/ElevenLabs, его +9 dB, личные показатели, кодовые слова, примеры аккаунтов, длительность 72.64 с, 25 fps и точные границы сцен принадлежат конкретному исходнику. Студент получает ту же систему монтажа и визуальный язык, с новыми словами, кропом, сценами и таймингами.

Объектная непрерывность, детализация и движение от общего вида к действию реализованы в эталоне 5 ноября. Они остаются принципом, а не поводом копировать конкретные окна, фразы или тайминги в чужой ролик. Эффект глубины хука является опциональным: он допустим только с маской, рассчитанной по текущему исходнику.
