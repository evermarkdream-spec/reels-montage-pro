# Установка для ученика

## Установка из GitHub — для агента

Репозиторий: https://github.com/evermarkdream-spec/reels-montage-pro

Скачайте весь репозиторий в отдельную папку `montage-kit` (git clone или ZIP). Не извлекайте только SKILL.md. Из папки комплекта создайте новый проект, затем скопируйте скилл в его локальный каталог навыков:

```bash
python3 scripts/bootstrap.py ../reel-project
python3 scripts/install.py --project ../reel-project --agent codex
```

Для Claude Code во второй команде используйте `--agent claude-code`. На Windows используйте доступный Python 3.11+ (`py -3.11` или `python`) вместо `python3`. Существующий рабочий проект не пересоздавайте: для него достаточно install.py, если скилла там ещё нет. Оба скрипта отказываются перезаписывать существующие папки.

Установщик копирует полный комплект: для Codex в `reel-project/.agents/skills/reels-montage-pro`, для Claude Code в `reel-project/.claude/skills/reels-montage-pro`. Откройте `reel-project` как рабочий проект. Если навык не появился в меню, переоткройте проект/чат; в текущем чате можно сразу прочитать установленный SKILL.md по пути.

Далее из `reel-project`: `python3 scripts/setup.py --check`, устранить недостающие зависимости, `python3 scripts/setup.py`. Сам install.py только копирует файлы: он не устанавливает системные программы и не запускает монтаж. Затем следуйте SKILL.md и WORKFLOW.md до готового MP4. В шаблон добавлен CLAUDE.md, направляющий Claude Code к общим правилам AGENTS.md.

Пути локальных навыков сверены с официальной документацией: [Codex](https://learn.chatgpt.com/docs/build-skills), [Claude Code](https://code.claude.com/docs/en/skills). Этот процесс рассчитан на локального агента с доступом к shell и файлам компьютера.

## Самый простой запуск

Скачайте полный ZIP, распакуйте его, откройте полученную папку в Codex или Claude Code и отправьте:

> Установи вот этот скилл и начинай: https://github.com/evermarkdream-spec/reels-montage-pro

Агент должен сам прочитать распакованный комплект, установить скилл в локальный каталог текущего проекта, подготовить рабочую папку и попросить исходник. Затем он запускает импорт и выполняет смысловой/визуальный проход. При вопросе по неоднозначной фразе или недостающему личному материалу ответьте конкретно. Последующие видео можно передавать в тот же подготовленный проект.

## Что устанавливается

Node.js с npm; Python 3.11+; FFmpeg и FFprobe в PATH. Далее project/scripts/setup.py устанавливает lock-файл npm и отдельное Python-окружение. Первая транскрипция загружает Whisper small, поэтому нужен интернет и место на диске. Дальше распознавание локальное. Сам AI-агент может обрабатывать текст и код в облаке в соответствии с настройками выбранного продукта.

Проект Remotion предназначен для запуска на обычном компьютере. Более мощный процессор ускоряет транскрипцию и рендер. Часовые исходники и 4K требуют больше времени и диска; прокси автоматически не создаются.

## Ручное развёртывание

Из папки скилла:

```bash
python scripts/bootstrap.py /path/to/new/reel-project
```

Откройте новую папку:

```bash
python scripts/setup.py --check
python scripts/setup.py
npm run dev
```

В Studio есть Style-Preview: обезличенное демо палитры, предметов и движения. Готовый эталон расположен отдельно в assets/reference/last-reel.mp4 внутри скилла. Чтобы монтировать, передайте агенту свой исходник и используйте WORKFLOW.md.

В Codex скилл вызывается как $reels-montage-pro после установки в доступный каталог skills. В Claude Code используйте поддерживаемую им установку навыков либо SKILL.md как инструкции проекта. Для первого запуска достаточно открыть распакованную папку и явно попросить прочитать SKILL.md. Сам промпт не добавляет браузер, подписки или инструменты, отсутствующие у агента.

## Что можно менять под себя

Язык, шрифты, размер субтитров, частота/крупность графики, музыка, хук и безопасные зоны. Для совпадения с эталоном сначала оставьте профиль по умолчанию. Затем опишите одну конкретную правку агенту, проверьте результат, сохраните её в профиле и правилах проекта.

Пример: «Сделай субтитры чуть крупнее, сохрани положение ниже стыка и весь остальной стиль». Попросите записать принятую правку в активный STYLE_PROFILE.md и обновить соответствующие настройки и код. Для разбора видео конкурентов и создания своего стиля используется STYLE_ADAPTATION.md в проекте; подробные промпты есть в STUDENT_GUIDE.md скилла. Прежние монтажи не должны молча перезаписываться. В новом чате открывайте тот же проект: только так сохранённые файлы правил снова будут доступны агенту.

## Что передать агенту вместе с видео

Обязателен сам исходник. Полезны правильные написания имён/сервисов, свои скриншоты и примеры результатов, точный текст предложения/CTA, выбранная музыка. Если речь про личную статистику, нужен настоящий скриншот. Если конкретный пример не нужен — разрешите условную предметную иллюстрацию.

## Что получите на выходе

MP4 1080×1920, проект Remotion с редактируемыми слоями, субтитры/транскрипцию, карту склеек, план сцен и отчёт о проверках. Скорость и качество первого результата зависят от исходника и возможностей AI-агента. Стиль задан заранее; сцены всё равно строятся под ваш смысл.
