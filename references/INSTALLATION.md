# Установка — инструкция агенту

Пользователь уже просит скачать и установить комплект. Выполни работу сам; не выдавай список команд для самостоятельного запуска и не останавливайся после копирования SKILL.md.

1. Скачай **весь** публичный репозиторий `https://github.com/evermarkdream-spec/reels-montage-pro` через git clone в свободную папку `montage-kit`. Без git скачай ZIP с `https://github.com/evermarkdream-spec/reels-montage-pro/archive/refs/heads/main.zip` и распакуй безопасно (без выхода за папку назначения). GitHub-аккаунт для скачивания не нужен. Уже установленный полный комплект можно использовать сразу.
2. Проверь Python 3.11+, Node.js с npm, FFmpeg/FFprobe. Используй существующие совместимые установки. Недостающее подготовь доступным системным пакетным менеджером или официальным установщиком в рамках разрешений среды. Не требуй от ученика разбираться в терминале. Если нужен пароль администратора или доступ запрещён, назови конкретный блокер и одно необходимое действие. Не обходи ограничения.
3. Выбери отдельную доступную рабочую папку `reel-project` **рядом с комплектом, вне каталога скилла**. Если это имя занято чужими файлами, возьми свободное. Из папки скачанного комплекта запусти:

```bash
python3 scripts/start.py --project ../reel-project --agent codex
```

Для Claude Code: `--agent claude-code`. На Windows используй доступный Python 3.11+ (`py -3.11` или `python`). Команда создаёт проект, копирует полный скилл, проверяет инструменты, ставит npm-зависимости по lock-файлу и Python-пакеты в проектное окружение. Повторный запуск продолжает только папку с собственным маркером; чужие папки и существующий скилл не перезаписываются. `--prepare-only` предназначен для офлайн-проверки упаковки и **не означает готовность к монтажу**.
4. Продолжи работу в созданной папке. Для Codex скилл находится в `.agents/skills/reels-montage-pro`, для Claude Code — `.claude/skills/reels-montage-pro`. Если меню ещё не обновилось, сразу прочитай SKILL.md по пути и выполни его; перезапуск чата нужен только для обнаружения через меню, не для чтения файла. Не копируй проект заново при уже выполненной установке.
5. Если исходник уже приложен, сразу монтируй. Иначе сообщи только: **«Пришлите исходный ролик — смонтирую в стиле „Монтаж ТОП“.»** Не проводи анкету по стилю: он уже настроен. Спросить правильное написание имени или конкретный недостающий материал можно, когда это реально нужно.
6. По SKILL.md доведи исходник до первого проверенного MP4 и редактируемого проекта. Импорт и транскрипция сами по себе не являются готовым монтажом.

Первое распознавание скачивает Whisper small; затем оно работает локально. Для загрузки зависимостей и весов нужен интернет. Агент может обрабатывать текст в облаке по настройкам выбранного продукта. Не отправляй видео во внешние сервисы без разрешения ученика.

## Уже существующий проект

Сначала прочитай его AGENTS.md, профиль и установленный SKILL.md. Для ручной установки в подготовленный проект есть `scripts/install.py --project PATH --agent codex`; для одного только нового шаблона — `scripts/bootstrap.py PATH`. Эти команды не перезаписывают существующие назначения. Не удаляй прежние монтажи при обновлении.
